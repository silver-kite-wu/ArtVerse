设计说明

百度百科式关系叙事的结构 + ArtVerse 现有设计语言
01 / LAYOUT

以人物为中心的环形双圈

当前中心人物居中放大，一层关系排内圈，两层关系排外圈。点击任意环上人物，即以他为中心重新构建：新中心放大、原中心退回环上，图谱始终围绕"当前正在看的人"。

02 / NODE

圆形头像 + 姓名下置

延续百科图谱的识别方式：圆形头像、姓名在下方。角色卡有封面时直接显示照片，没有则用姓名首字，避免空白占位感。

03 / FILTER

彩色关系筛选 chips

替代现有的两个下拉框。每类关系带色点与计数，点选即聚焦该关系；再次点击恢复全部。筛选状态与图例颜色一致，不需要额外图例学习。

04 / EDGE

细曲线 + 中点标签

关系标签做成线上小胶囊，保留箭头方向：单向一个箭头，对称关系两端箭头。待确认关系用琥珀虚线，隐藏信息用紫色小圆点标记，避免标签过长。

05 / PANEL

右侧档案抽屉

点击中心人物从右侧滑出档案：身份、直接关系、隐藏信息、证据引用与下一步操作。面板展开时画布同步缩放，避免边缘节点被遮住；节点可拖拽微调位置，中心节点固定不动。

06 / ADAPT

主题、窄屏与列表降级

全部颜色取自现有 token，暗色 / 亮色自动适配；窄屏时抽屉改为底部浮层；保留关系列表视图，表格同样带头像与审核状态。
