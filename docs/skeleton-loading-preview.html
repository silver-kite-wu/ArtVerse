ArtVerse. 骨架屏加载方案 v1 预览 · 待审核

Loading Experience / Design Proposal

让等待也有形状：
骨架屏 + 流动亮带统一方案

针对故事创作、小说广场、定时任务等「固定数据加载」场景，用与真实内容同构的骨架屏替代空白与转圈， 并在骨架上加入低对比、慢节奏的移动高光，让页面在数据到达前就建立结构预期。

覆盖 4 个页面 基础组件 1 个 支持 深色 / 浅色 动效 1.6s · 100° 亮带 可访问 reduced-motion
01

设计原则

骨架不是装饰，是内容结构的提前占位。

STRUCTURE

结构即内容

骨架尺寸、圆角、栅格与真实卡片保持一致，数据到达后不发生布局跳动。

SCOPE

只替换等待区域

页面标题、搜索框、筛选器等静态部分保持可见；只对正在取数的区域使用骨架。

RESTRAINT

低对比、慢节奏

高光只做轻微「呼吸」提示，不抢内容注意力。1.6s 循环，亮度不超过文字色 10%。

A11Y

可访问与降级

容器标记 aria-busy，提供 sr-only 加载文案；prefers-reduced-motion 下停用亮带。

02

Shimmer 视觉规范

沿用现有 Obsidian 中性色，不引入新的品牌色。

骨架色板

--skeleton-base dark #1B1B1E / light #E9E6DF
--skeleton-highlight dark rgba(242,242,239,.10) light rgba(255,255,255,.92)

基础色比 bg-surface 亮一档，与 bg-raised 接近；高光只提亮约 10%，避免「闪白」。

亮带参数

  • 角度100deg
  • 亮带占比16%
  • 背景尺寸240% 100%
  • 位移方向右 → 左
  • 循环时长1.6s
  • 缓动ease-in-out

状态与降级

  • 加载容器aria-busy="true"
  • 形状元素aria-hidden="true"
  • 屏幕阅读器sr-only「正在加载…」
  • 减少动态animation: none
  • 加载完成直接卸载，不淡出
  • 人为延时不引入
/* index.css — 统一骨架原语 */
:root {
  --skeleton-base: #1b1b1e;
  --skeleton-highlight: rgba(242, 242, 239, 0.10);
}
[data-mode="light"] {
  --skeleton-base: #e9e6df;
  --skeleton-highlight: rgba(255, 255, 255, 0.92);
}

.skeleton {
  background-color: var(--skeleton-base);
  background-image: linear-gradient(
    100deg,
    transparent 42%,
    var(--skeleton-highlight) 50%,
    transparent 58%
  );
  background-size: 240% 100%;
  background-repeat: no-repeat;
  animation: skeleton-shimmer 1.6s ease-in-out infinite;
  pointer-events: none;
  /* 圆角由页面与真实卡片保持一致，通过 rounded-* 控制 */
}

@keyframes skeleton-shimmer {
  0%   { background-position: 0% 0; }
  100% { background-position: 100% 0; }
}

@media (prefers-reduced-motion: reduce) {
  .skeleton { animation: none; background-image: none; }
}
为什么不用现有 .shimmer-bg？ 现有类仅用 accent-soft（深色下约 5.5% 白）作为亮带，实际几乎不可见， 且依赖外部 bg 类提供底色。新方案把「底色 + 亮带 + 动效 + 降级」收敛为一个 .skeleton 原语， 便于四个页面统一。生图占位仍保留 .shimmer-bg，二者语义不同。

08

实施方式

一个原语，四个页面组合；不引入依赖。

改动文件

  • frontend/src/index.css新增 skeleton token、keyframes、.skeleton 与 reduced-motion 规则
  • frontend/src/ui/Skeleton.tsx新增轻量 Skeleton 组件（div + aria-hidden）
  • components/HomePage.tsxloading 分支替换为工作区骨架组合
  • components/SquarePage.tsx列表骨架替换灰块；详情页增加骨架
  • components/automations/AutomationCenterPage.tsx列表与详情加载区域替换为骨架
  • components/MyWorksPage.tsx现有 shimmer-bg 迁移为 .skeleton

验收标准

  • 四个场景首次进入不再出现转圈或空白，骨架形状与最终内容一致。
  • 深色 / 浅色主题下亮带均可见，但不高于背景文字对比度。
  • prefers-reduced-motion 开启时无移动亮带，仅保留静态骨架。
  • 加载完成无布局跳动；翻页 / 搜索 / 切换任务时交互不阻塞。
  • 容器带 aria-busy，骨架形状 aria-hidden，并提供 sr-only 加载文案。
  • 不会为等待而人为增加延时；数据返回后立即卸载骨架。
// frontend/src/ui/Skeleton.tsx
import type { ComponentPropsWithoutRef } from 'react';

export function Skeleton({
  className = '',
  ...props
}: ComponentPropsWithoutRef<'div'>) {
  return (
    <div
      aria-hidden="true"
      className={`skeleton ${className}`}
      {...props}
    />
  );
}

// 页面侧只负责“摆形状”，不重复定义颜色与动画：
<Skeleton className="h-3 w-2/3 rounded-lg" />
