# ArtVerse 前端视觉优化

## 设计方向

以「安静、温暖的创作工作室」为主题。暖白纸感背景、墨绿色主视觉和陶土橙操作按钮共同建立品牌识别，让作品封面和创作内容承担视觉重点。

## 视觉规范

| 用途 | 浅色模式 | 深色模式 |
| --- | --- | --- |
| 页面背景 | `#F8F7F3` | `#171D1C` |
| 内容表面 | `#FFFFFF` | `#202725` |
| 主要文字 | `#28382F` | `#EDECE4` |
| 品牌强调文字 | `#A75134` | `#E2A080` |
| 主要操作按钮 | 陶土橙底、暖白文字 | 陶土橙底、暖白文字 |
| 主视觉 | `#294A40` 墨绿底、杏色点缀 | 同一品牌主视觉 |

- 统一中文无衬线字体回退、字号层次、轻量描边和阴影；品牌名称保留衬线字形。
- 常规控件采用小圆角，主视觉使用较大的圆角，减少多层套框。
- 导航选中状态同时使用背景、文字颜色和侧边标记，键盘焦点保持可见。
- 原创书页、山景和拱门插画由 `StudioArtwork.tsx` 绘制，不依赖远程图片。

## 页面改动

- **全局导航**：整理创作与探索分区，简化账号操作区，增加创作入口；收起后保留按钮名称。
- **作品广场**：增加品牌主视觉，重组作品类型、搜索和书架布局，统一卡片与空状态；保留搜索、分页和阅读路由。
- **故事工作区**：增加创作主视觉和新建、AI 生图、导入三个快捷入口；新建弹窗限制高度、允许滚动，并提供键盘关闭和封面上传入口。
- **章节编辑**：采用 IDEA 工具窗口布局，小说原文占据主区域，最右侧固定 48px 工具栏提供 AI 助手和漫画创作入口。面板默认收起，展开宽度默认 280px，可拖动并记忆宽度与展开状态；工作区域宽度不超过 720px 时采用覆盖式抽屉。切换工具保留输入与分镜草稿，正文支持保存和版本恢复；AI 请求与分镜生成前保存正文，AI 修改经作者确认并核对版本后写入。
- **AI 生图**：重做初始创作引导，增加可填入提示词的灵感按钮；手机端主题列表采用抽屉，输入区工具栏允许换行。
- **文字修改审阅**：优化／润色后在正文主区域展示段落差异，红删绿增并高亮改字；支持逐处保留原文、批量选择、折叠未改段落及编辑最终稿。作者确认直接保存其审阅结果并生成版本，手机端审阅入口会收起助手抽屉。设计与验证边界见 `../ArtVerse/docs/novel-text-review.md`。
- **其余页面**：通过共享语义颜色、字体、圆角、按钮和阴影同步视觉规范。
- **移动端**：修复底部导航定位被公共面板样式覆盖的问题，适配单列书架与小屏弹窗。

## 验证说明

### AI 输入区更新（2026-11-03）

- AI 助手与 AI 生图共用 `src/components/ai-composer.css`：单层圆角表面、细陶土色聚焦描边、低透明度光晕与轻量工具栏。模型选择采用无边框文字加小箭头，位于右下方发送按钮左侧；发送采用深色圆形白箭头，深色主题反转为浅色圆形深色箭头。
- 全局 `:focus-visible` 默认规则放入 Tailwind 的 `base` 层，避免无分层规则压过 `outline-none` 工具类；AI 输入样式从 `main.tsx` 显式加载，textarea / 模型搜索不绘制内层矩形，只由外层圆角容器反馈聚焦。按钮键盘轮廓与强制颜色模式的容器焦点保留。
- 模型菜单包含供应商分组和选中提示；浮层渲染到 body，以模型按钮自身右边缘为定位基准并保留 8px 间距，视口不足时避让边缘或改为向下展开。输入框只限制列表宽度；同时观察按钮、输入框和菜单的尺寸，避免辅助面板调宽或搜索结果变化后错位。方向键与 Enter 统一处理，Escape 返回触发器且不误关助手抽屉。
- 生图参考图入口支持 Tab 键访问，保留上传、粘贴、分辨率和预约流程；两处输入框均保护中文输入法合成过程，防止选词时误发送。
- 通过正式 React 页面的浏览器检查覆盖 320 / 390 / 768 / 1050 / 1440px、280px 助手面板、模型搜索及键盘选择、长名称、浅深主题、强制颜色、参考图添加移除、分辨率与模拟对话请求。使用会话内拦截数据，不向后端写入示例数据。真实模型生成与取消仍需可用后端环境验证。
